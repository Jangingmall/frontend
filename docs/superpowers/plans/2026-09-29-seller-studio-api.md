# 판매자 실제 API 연동 구현 계획

- 사용자 승인 범위: 기존 판매자 화면을 실제 백엔드 API로 개발한다. 기존 이슈 #94를 이어간다.
- 기준: frontend dev 5995bc6, backend develop 8402c5b.
- 기존 Figma 외형과 네 단계 흐름을 유지한다.
- 인증된 ARTISAN만 실제 요청한다. 시연 세션을 실제 저장으로 안내하지 않는다.
- 상품 등록(가격·재고 직접 입력), CONTENT 사진 3종 업로드, 생성 요청 및 상태 폴링, reactDocument 조회, 노드 텍스트·이미지 PATCH, 검수·승인·게시를 연결한다.
- 생성 중 URL에 productId/generationId를 기록해 새로고침을 복원한다. 실패하면 자동 재생성하지 않는다.
- 문서 ID와 구조를 유지하고 허용된 태그·스타일만 표시한다. 미지원 서식·순서 변경은 서버 편집에 제공하지 않는다.
- 서버 응답으로 저장/검수/게시 성공을 확인한다. 게시와 상품 ON_SALE 전환을 구분한다.
- 기존 브라우저 시연은 example 모드로 유지한다. 실제 API 화면은 기본 진입으로 제공하며 MSW도 같은 계약을 사용한다.
