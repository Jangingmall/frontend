# 판매자 상세페이지 스튜디오 화면

## 범위

사용자 요청: Figma 판매자 화면의 외형에 기존 로컬 프로토타입의 기능을 옮긴다.
브랜치 `feat/seller-studio-figma`, 관련 이슈 #94. 최신 `dev` a722454에서 분기한다.
이번 변경은 **시연 화면과 편집 기능 이식**이다. 실제 AI 생성, 판매자 인증·권한, 서버 저장·검수·게시 API는 구현하지 않았으며 #94의 해당 항목을 완료 처리하지 않는다. PR #97의 소비자 API/MSW 모드 변경과 별도다.

## 확인 경로

- `/seller/products/new`: 빈 입력 → 초안 구성 → 편집 → 최종 확인
- `/seller/products/new?example=1`: 기존 금속 다기 예시의 편집 화면
- `/seller/products`: 이 브라우저에 저장한 작업 목록
- `/seller/products/new?project=<id>`: 저장한 초안 또는 완료본 복원

Figma 도구 SVG를 `public/seller-studio`에 저장했다. 로고는 원본의 ‘로고’ 자리 표시자를 유지한다. 최종 확인의 정적인 상품 상세 스크린샷을 배경으로 사용하지 않고 실제 편집 결과를 렌더링한다. 가격·배송·옵션은 입력받지 않은 정보이므로 ‘미등록’으로 표시하며 가짜 구매 버튼은 제공하지 않는다.
좁은 화면에서는 폼을 가용 폭에 맞추고 편집 목록을 접는다. 미리보기 기기 전환은 문서 전체를 기준 폭에서 축소해 확인한다.

## 재사용한 프로토타입 기능

- `studio-contract`: Zod 기반 초안/AST 검증, 허용 태그 렌더링, 중복 ID·잘못된 이미지 참조 거부, 깊이·노드 수 제한
- `ContractPreview`: 검증한 AST만 React 요소로 렌더링, ResizeObserver 기반 문서 크기 조정
- 문구 및 특징 편집, 이미지 우선/이야기 우선/특징 배치, 순서 이동, 실행 취소·재실행
- 사진 교체/제거, 페이지 추가·복제·삭제, 배경 프리셋
- 브라우저 저장·새로고침 복원·저장 실패 시 현재 편집 보존

입력한 정보로 만드는 초안은 로컬 템플릿이며 실제 AI 모델을 호출하지 않는다. 생성 화면·입력 화면·최종 확인에 시연 상태를 명시한다. 이전 프로토타입의 다른 실험 화면(자동차/변환 HTML/v2)은 통합하지 않는다.

## 저장 계약과 제한

`midam-seller-figma-v1:<id>` 키에 검증한 초안, 이미지, 상태를 저장한다. 기존 프로토타입의 저장 키와 분리한다. 데이터 URL 이미지도 포함되므로 저장소 용량을 초과하면 실패 안내를 보여주고 편집 내용을 유지한다. 저장 실패 시 완료 화면으로 넘어가지 않는다. URL에는 저장 성공 후에만 ID를 반영한다.

- 원격 HTML·스크립트를 삽입하지 않는다. 복원 이미지 URL은 허용된 로컬 예시 및 래스터 데이터 URL만 허용한다.
- 데이터는 현재 브라우저에만 존재하며 계정·서버 간 동기화되지 않는다. 실상품 게시 상태를 변경하지 않는다.
- 판매자 경로는 공개 시연 화면이다. 운영 판매자 권한 및 실제 백엔드 연동은 #94의 별도 미완료 항목이다.
- 사진 추가·교체를 포함해 문구·순서·배치 변경을 실행 취소할 수 있다. 8장이 찬 경우 선택 사진을 새 파일로 교체할 수 있으며, 동일 사진을 사용한 모든 페이지에 반영된다.

## 검증

- 단위 테스트: 문서 AST 검증, 입력 필수값·개수 제한, 이력 분기, 손상된 저장 데이터
- Playwright: 업로드→생성→편집→저장→새로고침→최종 확인, 이미지 교체·배치·순서·페이지 추가, 저장 용량 실패, 390px 입력 화면 가로 넘침
- Figma 렌더와 1440px 입력/생성/편집/최종 확인 및 390px 입력 캡처 수동 비교
- 실행 결과와 캡처는 PR 본문에 기록

## 코드 리뷰 반영

- 모바일에서 페이지 구성 도구를 선택하면 목록·페이지 추가·배치 선택 패널을 펼친다.
- 사진 라이브러리가 8장이어도 선택 사진을 교체할 수 있고, 사진 상태와 문서 상태를 함께 실행 취소한다.
- 사진 준비 중에는 저장·완료·이력 이동·작업 목록 이동을 대기시켜 저장본과 화면이 달라지지 않도록 한다. 화면을 벗어난 후에는 비동기 업로드 결과를 반영하지 않는다.
