## 범위와 의존 작업

- GNB·메가패널·분류 코드 계약은 수정하지 않는다. GNB가 사용하는 분류 코드와 현재 Mock 목록 ID의 불일치는 별도 담당 작업이다.
- PL-3의 종목 다중 선택은 이번 UI 보완 범위에 포함하지 않는다.
- 운영 API, 목록 찜 mutation, 챗봇 모달은 별도 작업이다. AI CHAT은 기존 컴포넌트의 비활성 상태를 그대로 재사용한다.
- 카테고리가 없는 목록의 기존 경로 표시·카드·그리드·결과 수 표현과 플로팅 노출 여부는 유지한다. 정렬 메뉴는 공통 컴포넌트의 수정된 문구·순서를 사용한다.
