## 적용 범위

Figma 지적 스크린샷은 기존 시연 편집기 기준이다. 공통 헤더 및 도움말은 실제 API 편집기에도 적용한다. 실제 API 응답 reactDocument와 원본 노드 ID, 글/사진 PATCH 계약은 유지한다. 서버 API가 지원하지 않는 서식·순서·노드 추가/삭제는 서버에 저장한 것처럼 표시하지 않는다.

## 검증

- 위 표의 헤더, 아이콘, 배경, 간격, 도움말 및 툴팁을 반영했다.
- 시연 편집기에 정렬·굵기·색상·제목 크기 도구를 추가했다. 선택하지 않은 서식은 기존 값을 유지하며 브라우저 저장·복원 및 실행 취소에 포함된다.
- 글 서식은 선택 페이지의 작은 제목·제목·설명에 함께 적용한다. 개별 문장 선택 서식은 포함하지 않는다.
- 실제 API 편집기는 공통 헤더와 도움말을 적용했다. 시연용 서식 도구는 서버 PATCH 계약에 없으므로 실제 API 편집기로 확장하지 않았다.
- 독립 코드 리뷰에서 발견한 먹색 배경 글자색 손실과 작은 제목 정렬 문제를 보완하고 회귀 테스트를 추가했다.
