# 현재 화면의 API / MSW 연결

2026-09-30, `dev`의 실제 API 계약을 유지한 미지원 기능 복원 기준입니다. 2026-09-29의 시연 비활성화 기록보다 이 문서를 우선합니다.

## 실행 방식

- `npm run dev:msw`: 모든 API를 MSW로 시연합니다.
- `API_BASE_URL`을 실제 백엔드로 지정하고 `npm run dev:api`: 구현된 기능은 실제 API, 아래 미지원 화면 기능은 별도 MSW 모듈을 사용합니다.
- `.env.local`의 `NEXT_PUBLIC_DATA_MODE=msw|api`로도 설정할 수 있습니다. 변경 후 재시작/재빌드가 필요합니다.
- `NEXT_PUBLIC_API_MOCKING=enabled`는 전체 MSW의 이전 설정이며 `DATA_MODE=api`와 함께 설정하지 않습니다.
- Vercel production에서는 전체 MSW 인증을 계속 차단합니다. API 모드의 허용된 시연 화면은 사용할 수 있습니다.

## 실제 API를 유지하는 부분

기존 `src/api/products/api.ts`, `client.ts`, `query.ts`, `backend-list.ts`, `detail-api.ts`, `detail-actions.ts`, 회원·주문·결제·판매자 API의 URL 및 DTO는 변경하지 않습니다. 화면 조회 훅과 새 `catalogue-client.ts` / `catalogue-server.ts`가 미지원 목록만 별도 시연 모듈로 보냅니다.

| 기능                                          | API 모드 동작                                        |
| --------------------------------------------- | ---------------------------------------------------- |
| 일반 목록, 검색, 인기순·최신순·가격순         | 기존 실제 상품 API                                   |
| 분류·소분류·소재 선택지                       | 기존 실제 API. 소재 선택지가 빈 배열이면 그대로 표시 |
| 홈 신상품·선물·장인                           | 기존 실제 API                                        |
| 상품 상세·찜·장바구니 담기                    | 실제 상품은 기존 실제 API                            |
| 일반 후기·내 후기·후기 작성                   | 기존 실제 API                                        |
| 공개 상품 문의 작성                           | 기존 실제 POST `/api/products/:id/questions`         |
| 이메일·카카오 로그인, 회원 정보, 배송지       | 기존 실제 API·권한 검사                              |
| 장바구니 수량·입력형 옵션 변경                | 기존 실제 API                                        |
| 실제 주문 생성·Toss 결제·완료 조회            | 기존 실제 API. 시연 할인과 합산하지 않음             |
| 주문 내역·배송·구매확정·교환/반품·미결제 취소 | 기존 실제 API                                        |
| 판매자 스튜디오·이미지 업로드·AI 생성         | 기존 실제 API. 오류를 시연 성공으로 대체하지 않음    |

## 복원하는 시연 화면

| 화면                                         | 동작 / 구분                                                                              |
| -------------------------------------------- | ---------------------------------------------------------------------------------------- |
| 홈 베스트·기획전, 베스트 메뉴                | 시연 카탈로그로 표시                                                                     |
| 판매량순·찜 많은 순·소재/공예/선물 포장 필터 | 결과 전체를 시연 카탈로그로 표시. 기본 실제 목록으로 돌아갈 수 있음                      |
| 시연 상품 상세·찜·장바구니                   | `preview=1`을 유지. 시연 상품 ID를 실제 구매 요청에 사용하지 않음                        |
| 사진 후기 필터                               | 시연 사진 후기로 표시, 일반 후기로 복귀하면 실제 API                                     |
| 상품 문의 목록                               | 시연 데이터. 실제 비밀 답변 조회는 호출하지 않음                                         |
| 문의 작성 시연                               | 별도 버튼으로 열고 MSW에만 저장. 기존 공개 문의 작성과 구분                              |
| 재입고 알림                                  | 시연 신청이며 실제 알림은 발송하지 않음                                                  |
| 장바구니 선택형 옵션                         | 실제 옵션 변경 창에서 명시적으로 시연 장바구니로 이동. 실제 수량·입력형 옵션 변경 유지   |
| 쿠폰·적립금·할인코드·무통장입금              | 실제 결제 화면의 시연 버튼으로 고정 `ui-preview-order` 화면 진입. 실제 주문/PG 호출 없음 |
| 시연 주문 완료                               | 완료 화면에 시연 표시. 실제 주문 내역에는 기록되지 않음                                  |

시연 카탈로그는 기존 키친·다이닝 자료 범위입니다. 실분류 ID는 이름으로 기존 시연 분류에 대응합니다. 대응할 자료가 없으면 임의의 다른 상품 대신 오류를 표시합니다. 시연 할인코드는 `MIDAM10`, 적립금은 3,000원, 쿠폰은 2,000원입니다.

## 경계와 유지한 제한

- API 모드는 `lib/data-mode.ts`의 경로·메서드 허용 목록에 있는 `/api/mock/*`만 처리합니다. `/api/member/*`, `/api/payments/*`, 판매자/AI API를 가로채지 않습니다.
- 실제 401·404·500과 빈 목록은 실제 결과대로 처리합니다. 오류 뒤 MSW 성공으로 전환하지 않습니다.
- 시연 요청은 실제 Bearer 토큰을 필요로 하지 않습니다. 사용자의 시연 상태는 기존 `X-Demo-Viewer` 식별자로 분리합니다.
- SSR은 MSW resolver에서 명시적 시연 경로만 처리하며 실제 프록시 요청을 전역 가로채지 않습니다. 알 수 없는 시연 경로는 501 또는 클라이언트 오류이며 실서버로 보내지 않습니다.
- 로그인/권한은 변경하지 않습니다. API 모드의 네이버 가짜 로그인·`/api/mock/session/*` 활성화는 복원하지 않았습니다.
- 실제 결제된 주문의 취소 제한은 유지합니다. 실제 주문 상태를 시연 취소 결과로 변경하지 않습니다.
